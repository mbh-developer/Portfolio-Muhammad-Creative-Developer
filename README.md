# Creative Developer Portfolio Website

## How to use this project:
1. Extract this ZIP file into your project folder.
2. Open the folder in **Antigravity** or your preferred code editor (VS Code, etc.).
3. **What you need to customize/do:**
   - **Personal Info:** Open `index.html` and replace placeholder texts like "WB" with your initials, and update your bio/location if needed.
   - **Images:** Add your portrait picture inside the `assets/` folder and link it in the About section (`assets/profile.jpg`). Add project screenshots to showcase your work.
   - **Links:** Update your GitHub, LinkedIn, and Email URLs in the contact and footer sections.
4. Run or preview `index.html` in your browser to see your live portfolio!
